Éditeur du portfolio

Pour enregistrer tes changements sur le site, l'éditeur a besoin d'un jeton GitHub (à créer une seule fois).

Comment créer le jeton (2 minutes)
  1. Ouvre GitHub › Settings › Developer settings › Fine-grained tokens › Generate new token.
  2. Nom : « Éditeur portfolio ». Expiration : 1 an.
  3. Repository access : « Only select repositories » › Paulleb08/portfolio.
  4. Permissions : Contents : Read and write et Issues : Read and write.
  5. « Generate token », copie-le (il commence par github_pat_) et colle-le ici. Il reste seulement sur cet appareil.
